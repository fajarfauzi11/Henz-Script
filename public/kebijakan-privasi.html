1. Pendahuluan

Henzscript.com ("Henz MLBB", "kami") adalah situs komunitas berbagi script skin Mobile Legends: Bang Bang. Kebijakan ini menjelaskan informasi apa yang kami kumpulkan saat kamu mengunjungi situs ini, bagaimana informasi itu digunakan, dan layanan pihak ketiga mana saja yang terlibat. Dengan menggunakan situs ini, kamu dianggap telah membaca dan memahami kebijakan berikut.

2. Informasi yang kami kumpulkan

Situs ini tidak memiliki sistem pendaftaran akun, login, atau formulir yang meminta nama, email, atau nomor telepon secara langsung ke server kami. Fitur "Request Script" dan "Lapor Bug" mengarahkanmu ke grup WhatsApp atau Telegram eksternal, jadi apa pun yang kamu ketik di sana tersimpan dan dikelola oleh WhatsApp/Telegram, bukan oleh kami.

Yang kami kumpulkan hanya data agregat dan anonim, yaitu jumlah tampilan tiap halaman post, untuk mengetahui skin mana yang paling banyak diminati. Angka ini tidak terhubung ke identitas siapa pun.

3. Layanan pihak ketiga yang kami gunakan

Situs ini berjalan di atas beberapa layanan pihak ketiga, masing-masing punya kebijakan privasinya sendiri, dan sebagian dari mereka bisa memproses data secara otomatis (seperti alamat IP) saat halaman dimuat:

  • Vercel — penyedia hosting kami, juga menjalankan Vercel Web Analytics untuk memantau performa situs secara agregat.
  • Upstash Redis — menyimpan angka hitungan tampilan yang disebut di atas.
  • Google Fonts — memuat huruf Manrope, Plus Jakarta Sans, dan Barlow langsung dari server Google.
  • Adsterra — jaringan iklan yang menampilkan banner dan tautan iklan (Direct Link/SmartLink) di situs ini, termasuk pada popup download. Adsterra dapat menggunakan teknologi pelacakannya sendiri untuk mengukur dan menayangkan iklan.
  • WhatsApp, Telegram, dan YouTube — untuk channel komunitas, request script, dan lapor bug.
  • Saweria — platform donasi pihak ketiga; transaksi ditangani sepenuhnya oleh Saweria.
  • Penyedia file eksternal (seperti sfile.co dan sejenisnya) — file script yang kamu download dihosting oleh pihak ketiga tersebut, bukan server kami.

4. Cookie dan penyimpanan lokal browser

Situs ini menyimpan sejumlah kecil data langsung di browsermu (localStorage/sessionStorage), bukan di server kami, untuk keperluan berikut:

  • Mengingat apakah kamu sudah menutup popup selamat datang, supaya tidak muncul berulang.
  • Mengatur jeda waktu antar-tampilan tautan iklan pada popup download, supaya tidak muncul terlalu sering dalam satu sesi.

Data ini bisa kamu hapus kapan saja lewat pengaturan browser, dan tidak digunakan untuk mengidentifikasi kamu secara pribadi.

5. Bagaimana kami menggunakan informasi

Informasi agregat yang kami miliki (hitungan tampilan) hanya digunakan untuk memahami skin dan konten mana yang paling diminati, sehingga kami bisa memprioritaskan pembaruan. Kami tidak menjual atau menyewakan data kepada pihak lain.

6. Hak kamu sebagai pengunjung

Karena kami tidak menyimpan data pribadi di server kami, tidak ada akun atau profil yang perlu kamu minta hapus dari kami. Untuk data yang tersimpan di browsermu sendiri, kamu bisa menghapusnya kapan saja lewat pengaturan browser. Untuk pertanyaan soal data yang kamu bagikan di WhatsApp, Telegram, atau Saweria, silakan hubungi masing-masing platform tersebut.

7. Privasi anak-anak

Mobile Legends: Bang Bang punya banyak pemain di bawah 18 tahun, tapi situs ini tidak secara sengaja mengumpulkan data pribadi dari siapa pun, termasuk anak-anak, karena memang tidak ada formulir pengumpulan data di situs ini.

8. Perubahan kebijakan ini

Kami dapat memperbarui kebijakan ini sewaktu-waktu, misalnya saat menambah layanan pihak ketiga baru. Tanggal "Berlaku sejak" di atas akan diperbarui setiap kali ada perubahan.
